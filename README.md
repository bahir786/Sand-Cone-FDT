# Sand Cone Field Density Test Calculator (ASTM D1556)

Developed by: Abdul Basir Bahir

## How to publish this as a website (needed for GitHub Pages / PWABuilder)

1. Create a free account at https://github.com
2. Create a new repository (e.g. `sand-cone-fdt`)
3. Upload all files from this folder (`index.html`, `manifest.json`, `sw.js`, and the `icons` folder) to that repository
4. Go to the repository's **Settings → Pages**
5. Under "Source", select your branch (usually `main`) and Save
6. After a minute or two, your site will be live at:
   `https://YOUR-USERNAME.github.io/sand-cone-fdt/`
7. Use that link in PWABuilder (https://www.pwabuilder.com) to package it as an Android APK

## Files
- `index.html` — the calculator app (HTML + CSS + JS, all in one file)
- `manifest.json` — PWA manifest (name, icons, colors, display mode)
- `sw.js` — service worker (enables offline use)
- `icons/icon-192.png`, `icons/icon-512.png` — app icons
