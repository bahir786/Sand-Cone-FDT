Description

A professional field calculator for construction materials laboratories. It performs ASTM D1556 sand cone density calculations, keeps a history of completed tests on this device, and generates printable PDF reports for each test.

Privacy Policy

Local Data Only

This application stores all test data, laboratory settings, and history only on your own device, using your browser's local storage. Nothing is uploaded or sent to any server.

What is Stored

Laboratory reference values, company and laboratory names, test measurements, calculated results, and your saved test history.

Clearing Data

You can erase all saved data at any time from Settings → Clear Saved Data. This cannot be undone.
